# Invitación de cumpleaños - Mariposas 🦋

Proyecto web hecho con HTML, CSS y JavaScript.

## Cómo abrirlo

1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html`.
3. Usa Live Server si lo tienes instalado, o abre el archivo directamente en el navegador.

## Datos que debes cambiar

En `index.html`:
- Nombre: Valentina
- Fecha: 18 de octubre de 2026
- Hora: 4:00 p. m.
- Lugar: Jardín Las Mariposas, Guadalajara, Jalisco
- Enlace de Google Maps
- Número de WhatsApp

En `js/app.js`:
- Cambia la fecha de `eventDate` para que el contador funcione con tu fecha real.

## Foto

Pon la foto de tu bebé dentro de:

`img/bebe.jpg`

El diseño ya está preparado para mostrarla.

## Música

Crea una carpeta `audio`, agrega un archivo llamado:

`musica.mp3`

Después descomenta el `<source>` dentro de `index.html`.

Nota: los navegadores móviles normalmente requieren una interacción del usuario antes de reproducir música. Por eso la música está preparada para iniciar después de pulsar "Abrir invitación".
